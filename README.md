**ID Print** is a lightweight, privacy-first Android application built to help print shopkeepers and cyber cafés merge the front and back sides of ID cards (such as Aadhaar or PAN cards) into a single, print-ready A4 PDF in seconds.

---

## 🎯 The Problem It Solves
Shopkeepers frequently receive front and back photos of customer ID cards via WhatsApp and have to manually join them, crop borders, convert JPGs to PDF, and upload sensitive KYC documents to ad-heavy third-party websites. **ID Print** automates this entire workflow locally on the device—saving time at the counter while keeping customer data completely private.

---

## ✨ Key Features
* **🔒 100% Local & Private:** Zero cloud uploads or external servers. All image cropping and PDF generation happen strictly offline on the device.
* **⚡ Two-Step Upload Flow:** Quickly select or import the **Front** and **Back** images from the gallery or WhatsApp folder.
* **✂️ Smart Auto-Crop + Manual Adjust:** Automatically detects card edges on upload, with a manual crop option for fine-tuning whenever needed.
* **📄 Clean A4 PDF Export:** Generates a crisp, print-ready A4 PDF with both sides neatly aligned and zero UI artifacts or crop handles.
* **🛠️ Automated CI/CD Releases:** Built and packaged automatically via GitHub Actions on every update.
* **📬 24/7 Automated User Support:** Built-in feedback routing paired with instant automated email confirmations and categorized response templates.
